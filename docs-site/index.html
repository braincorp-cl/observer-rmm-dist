¿Qué es Observer RMM?What is Observer RMM?

Observer RMM es una plataforma de monitoreo y administración remota (RMM) para flotas de equipos Windows, Linux y macOS. Desde una sola consola puedes vigilar el estado de cada equipo, ejecutar scripts y tareas, tomar control remoto y mantener el software al día.

Observer RMM is a remote monitoring and management (RMM) platform for fleets of Windows, Linux, and macOS machines. From a single console you can watch the health of every machine, run scripts and tasks, take remote control, and keep software up to date.

La plataforma se organiza en tres niveles: clientes (organizaciones), sitios (ubicaciones dentro de un cliente) y agentes (los equipos administrados). Empieza por Primeros pasos para dejar esa estructura lista y enrolar tu primer equipo.

The platform is organized in three levels: clients (organizations), sites (locations within a client), and agents (the managed machines). Start with Getting started to set up that structure and enroll your first machine.
