Los componentesThe components

El corazón de la plataforma vive en el servidor de aplicación. Todo el tráfico entra por un reverse proxy que termina TLS y preserva la IP real del cliente.

The heart of the platform lives in the application server. All traffic enters through a reverse proxy that terminates TLS and preserves the client's real IP.

  • Consola Web — la interfaz de operación, servida como archivos estáticos.
  • API RMM — la puerta de entrada REST; autentica por token y coordina todo lo demás.
  • Workers — ejecutan las tareas asíncronas (parches, scripts, reportes) tomándolas de una cola / broker.
  • Bus de mensajes — el canal por el que los agentes hacen check-in y reciben instrucciones.
  • Base de datos — el estado de toda la flota.
  • Control remoto — sesiones de escritorio y shell hacia los equipos.
  • CDN de agentes — sirve los instaladores firmados y sus actualizaciones.
  • Flota de agentes — los equipos administrados: Windows, Linux y macOS.
  • Web Console — the operator interface, served as static files.
  • RMM API — the REST entry point; authenticates by token and coordinates everything else.
  • Workers — run the asynchronous jobs (patching, scripts, reports), pulling them from a queue / broker.
  • Message bus — the channel agents use to check in and receive instructions.
  • Database — the state of the whole fleet.
  • Remote control — desktop and shell sessions to the machines.
  • Agent CDN — serves signed agent installers and their updates.
  • Agent fleet — the managed machines: Windows, Linux, and macOS.

El código se despliega al servidor desde el repositorio con CI/CD por HTTPS, y este mismo sitio de documentación es estático y autocontenido.

Code is deployed to the server from the repository via CI/CD over HTTPS, and this documentation site itself is static and self-contained.
