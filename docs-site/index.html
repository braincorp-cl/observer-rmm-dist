¿Qué es Observer RMM?

Observer RMM es una plataforma de monitoreo y administración remota (RMM) para flotas de equipos Windows, Linux y macOS. Desde una sola consola puedes vigilar el estado de cada equipo, ejecutar scripts y tareas, tomar control remoto y mantener el software al día.

La plataforma se organiza en tres niveles: clientes (organizaciones), sitios (ubicaciones dentro de un cliente) y agentes (los equipos administrados). Empieza por Primeros pasos para dejar esa estructura lista y enrolar tu primer equipo.
