Versión de **seguridad del almacén de claves**: los valores secretos dejan de salir por la consola, la API y la auditoría. Incluye además una corrección del despliegue de MeshCentral.

## Cambios en esta versión

### Almacén de claves: valores secretos

- **Cada clave tiene una marca de «Secreto».** Una clave secreta no muestra su valor en la tabla. Aparece con un candado y el estado «Secreto guardado» o «Secreto sin valor», y desapareció el botón Mostrar/Ocultar.
- **La API no devuelve el valor de una clave secreta.** Sólo informa si tiene un valor guardado.
- **Editar sin reescribir.** Si al editar una clave secreta se deja el valor vacío, se conserva el guardado. Al crear una clave el valor es obligatorio. Para quitarle la marca de secreto a una clave hay que escribirle un valor nuevo, así el valor guardado nunca se revela.
- **La auditoría deja de guardar el valor.** El registro de una clave guarda una huella del valor (HMAC), que permite saber si cambió sin exponerlo. En las acciones URL, el registro guarda una huella de las cabeceras. La prueba de una acción URL registra sólo los nombres de las cabeceras y la plantilla del cuerpo, no el cuerpo con los valores ya reemplazados.

### Instalación y operación

- **Corregido: el rol de MeshCentral actualizaba la versión en disco pero no reiniciaba el servicio.** El playbook terminaba en verde, pero el proceso seguía corriendo la versión anterior. Ahora el reinicio se dispara sólo cuando la actualización cambió algo, y una corrida sin cambios no reinicia.

## Agente

Se acompaña con el agente **2.18.5**, sin cambios respecto de la 1.4.43.

## Actualización

- **Hay una migración de base de datos nueva** (`core/0078`). Agrega la marca de secreto, y todas las claves existentes quedan como secretas, salvo `actividad_categorias`.
- **Antes de actualizar, revisa la lista de claves del almacén.** Una clave que se usa como configuración visible queda oculta después de la migración. Para volver a dejarla visible hay que editarla, quitarle la marca de secreto y escribir su valor de nuevo.
- Los registros de auditoría anteriores a esta versión no se modifican: conservan lo que se guardó en su momento.
- Si MeshCentral cambia de versión durante el despliegue, el servicio se reinicia y se cortan las sesiones remotas abiertas.
