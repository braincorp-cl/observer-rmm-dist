ReportesReports

El Gestor de reportes convierte los datos de tu flota en documentos presentables —inventario, parches, alertas, antivirus y más—. Los reportes vienen listos de fábrica: los generas, los descargas en PDF o HTML, los programas y los envías por correo. ¿Necesitas uno a medida? Lo pides al área de Soporte.

The report manager turns your fleet data into presentable documents —inventory, patches, alerts, antivirus, and more—. Reports come ready out of the box: you generate them, download them as PDF or HTML, schedule them, and email them. Need a custom one? Request it from Support.

Antes de empezar

Necesitas un usuario con permiso de Reportería (ver Permisos y seguridad) y al menos un agente enrolado con datos, para que los reportes tengan de dónde leer. Encontrarás todo en el menú Reportes → Gestor de reportes.

Before you begin

You need a user with the Reporting permission (see Permissions & security) and at least one enrolled agent with data, so reports have something to read. You'll find everything under the Reports → Report manager menu.

Reportes personalizados

La creación y edición de plantillas por parte del usuario está deshabilitada: los reportes los diseña y mantiene BrainCorp para que salgan consistentes. Si necesitas un reporte a medida —otros campos, otro formato, el logo de tu institución—, escríbele al área de Soporte y lo sumamos al Gestor.

Custom reports

User creation and editing of templates is disabled: reports are designed and maintained by BrainCorp so they come out consistent. If you need a tailored report —different fields, a different format, your organization's logo—, write to Support and we'll add it to the manager.

Cómo funciona la reportería, por dentroHow reporting works, under the hood

El dato nace en el agente de cada equipo: sus chequeos, actualizaciones de Windows, inventario de software y datos del sistema viajan al servidor por dos canales —el check-in por NATS (el servicio natsapi escribe el estado del equipo) y los envíos HTTP de apiv3— y se recolectan de toda la flota en la base de datos PostgreSQL observerrmm. Cuando pides un reporte desde la Consola (frontend), la API Django invoca el motor de reportería (ee.reporting): consulta esos datos con el ORM (solo los modelos permitidos), arma la plantilla con Jinja + Markdown y produce la salida —HTML, o PDF con WeasyPrint y gráficos rendidos por Kaleido—. Para programar, Celery Beat dispara cada minuto al worker, que genera el reporte, guarda el historial y, si corresponde, lo envía por correo vía SMTP a los destinatarios.

The data originates in each machine's agent: its checks, Windows updates, software inventory, and system data travel to the server over two channels —the NATS check-in (the natsapi service writes the machine's state) and apiv3 HTTP posts— and are collected across the whole fleet into the PostgreSQL observerrmm database. When you request a report from the Console (frontend), the Django API invokes the reporting engine (ee.reporting): it queries that data through the ORM (only the allowed models), assembles the template with Jinja + Markdown, and produces the output —HTML, or PDF via WeasyPrint with charts rendered by Kaleido—. For scheduling, Celery Beat triggers the worker every minute, which generates the report, saves the history and, when configured, emails it over SMTP to the recipients.

1. Generar un reporte1. Generate a report

No necesitas diseñar nada. Observer trae un conjunto de plantillas curadas listas para usar: eliges una, indicas sobre qué equipos aplicarla y obtienes un PDF (o HTML) con datos reales.

You don't need to design anything. Observer ships a set of ready-to-use curated templates: you pick one, tell it which machines to cover, and get a PDF (or HTML) with real data.

Desde el Gestor de reportesFrom the report manager

  1. Abre el menú Reportes → Gestor de reportes.
  2. En la lista, cada fila muestra el Nombre, el Tipo de plantilla y sus Dependencias (qué necesita para ejecutarse).
  3. Haz clic con el botón derecho sobre la plantilla que quieras y elige Abrir reporte PDF / Abrir reporte HTML (lo ves en el navegador) o Descargar reporte PDF / Descargar reporte HTML (lo guardas en tu equipo). Un doble clic sobre la fila también abre el reporte.
  4. Si la plantilla pide dependencias, aparece el diálogo «Seleccionar dependencias del reporte»: elige el Cliente, Sitio o Agente correspondiente y pulsa Enviar.
  5. El reporte se genera con los datos reales de tu flota y se abre o se descarga.
  1. Open the Reports → Report manager menu.
  2. In the list, each row shows the Name, the Template type, and its Dependencies (what it needs to run).
  3. Right-click the template you want and choose Open report PDF / Open report HTML (view it in the browser) or Download report PDF / Download report HTML (save it to your machine). Double-clicking the row also opens the report.
  4. If the template asks for dependencies, the «Select report dependencies» dialog appears: pick the matching Client, Site, or Agent and click Submit.
  5. The report is generated with your fleet's real data and opens or downloads.
Aún más rápido

Desde la ficha de un equipo, cliente o sitio también puedes generar un reporte directo con su menú de acciones (Ejecutar reporte de… / Descargar reporte de…). Ahí solo aparecen las plantillas aplicables a ese nivel y la dependencia ya viene resuelta: solo eliges plantilla y formato.

Even faster

From a machine, client, or site view you can also generate a report straight from its actions menu (Run report for… / Download report for…). There only the templates applicable to that level appear and the dependency is already resolved: you just pick a template and format.

Entender la columna «Dependencias»Understanding the «Dependencies» column

La columna Dependencias te dice qué debes indicar antes de ejecutar una plantilla:

The Dependencies column tells you what you must provide before running a template:

  • cliente, sitio o agente — la plantilla se acota a ese cliente, sitio o equipo; te lo pedirá al ejecutar.
  • Sin dependencias — la plantilla corre sobre toda la flota y se ejecuta de inmediato, sin diálogo previo.
  • client, site, or agent — the template is scoped to that client, site, or machine; it will ask you when you run it.
  • No dependencies — the template runs over the whole fleet and executes right away, with no prompt.
Ver en HTML o PDF

El mismo reporte se puede ver en HTML o cambiar el formato a PDF. Los reportes de tipo panel combinan indicadores y gráficos; el PDF sale paginado y listo para adjuntar o imprimir.

View as HTML or PDF

The same report can be viewed as HTML or switched to PDF. Dashboard-type reports combine indicators and charts; the PDF comes paginated and ready to attach or print.

Enviar por correo una vez

Además de abrir o descargar, la acción Enviar reporte por correo despacha el reporte por email en el momento. Para que se genere y se envíe solo, de forma recurrente, usa las programaciones.

Email it once

Besides opening or downloading, the Email report action sends the report by email on the spot. To have it generated and sent automatically on a recurring basis, use schedules.

3. Programar y enviar por correo3. Schedule and email

En vez de generar un reporte a mano cada vez, puedes programarlo para que se genere y se envíe por correo solo, de forma recurrente. Y en el historial encuentras todo lo que ya se generó.

Instead of generating a report by hand every time, you can schedule it so it's generated and emailed automatically on a recurring basis. And in the history you'll find everything already generated.

3.1 Programaciones3.1 Schedules

Desde la pestaña Programaciones de reportes, pulsa Nuevo y completa:

From the Report schedules tab, click New and fill in:

  1. Plantilla de reporte — cuál se generará. Si tiene Dependencias (cliente/sitio/agente), las fijas aquí para que corran siempre igual.
  2. Formato — PDF, HTML o Texto plano (o CSV).
  3. Programación — elige una existente o usa Crear nueva programación. El editor de recurrencia es visual, no requiere sintaxis: eliges el Tipo de ejecución (Diaria, Semanal o Mensual), la Hora:Minuto y, según el caso, los días de la semana, los días del mes o los meses.
  4. Zona horaria — la hora se interpreta en esta zona; si la dejas en blanco se usa la zona horaria por defecto de la plataforma.
  5. Habilitado — deja la programación activa (o desactívala sin borrarla).
  1. Report template — which one is generated. If it has Dependencies (client/site/agent), you fix them here so runs are always consistent.
  2. Format — PDF, HTML, or Plain text (or CSV).
  3. Schedule — pick an existing one or use Create new schedule. The recurrence editor is visual, no syntax needed: you choose the Run type (Daily, Weekly, or Monthly), the Hour:Minute and, as applicable, the weekdays, days of month, or months.
  4. Timezone — the time is interpreted in this zone; leave it blank to use the platform's default timezone.
  5. Enabled — leave the schedule active (or disable it without deleting).

Envío por correoEmail delivery

Con Enviar reporte por correo activo, defines los Destinatarios de correo con Agregar correo. Si no agregas ninguno, se usan los destinatarios por defecto de la configuración global; los que agregues aquí anulan ese valor por defecto. Con Personalizar contenido del correo puedes fijar el Asunto, el Cuerpo, el nombre y la extensión del adjunto (p. ej. csv) e incluir un enlace directo para ver el reporte en línea.

With Send report by email on, you set the Email recipients using Add email. If you add none, the default recipients from the global settings are used; the ones you add here override that default. With Customize email content you can set the Subject, the Body, the attachment name and extension (e.g. csv), and include a direct link to view the report online.

Requiere correo saliente

El envío automático solo funciona si el servidor SMTP está configurado. Revisa Alertas por correo para dejar el correo saliente operativo.

Requires outbound email

Automatic delivery only works if the SMTP server is configured. See Email alerts to get outbound email working.

Probar sin esperar

Con Ejecutar reporte programado disparas la programación en el momento —útil para comprobar que el reporte y el correo salen bien antes de confiar en el calendario—. La columna Última ejecución te muestra cuándo corrió por última vez.

Test without waiting

With Run scheduled report you trigger the schedule on the spot —handy to confirm the report and email come out right before trusting the calendar—. The Last run column shows when it last ran.

3.2 Historial3.2 History

La pestaña Historial de ejecución de reportes guarda cada reporte generado —manual o programado—. Para cada entrada ves la Plantilla, el Tipo de plantilla y la Fecha de creación, y puedes Abrir o Descargar el PDF (o el formato correspondiente) sin volver a generarlo.

The Report run history tab keeps every generated report —manual or scheduled—. For each entry you see the Template, the Template type, and the Date created, and you can Open or Download the PDF (or the matching format) without regenerating it.

4. Reportes personalizados4. Custom reports

Los reportes los diseña y mantiene BrainCorp: así salen consistentes y probados para toda la flota. Si el catálogo de fábrica no cubre exactamente lo que necesitas —otros campos, otro formato, un filtro distinto, el logo de tu institución en el encabezado—, solicítalo al área de Soporte. Lo diseñamos y lo sumamos al Gestor de reportes, donde queda disponible junto al resto.

Reports are designed and maintained by BrainCorp: that keeps them consistent and tested across the whole fleet. If the factory catalog doesn't cover exactly what you need —different fields, a different format, a different filter, your organization's logo in the header—, request it from Support. We design it and add it to the report manager, where it becomes available alongside the rest.

Qué incluir en tu solicitud

Para agilizar, cuéntanos: qué información quieres ver (equipos, software, parches, alertas…), cómo agruparla (por cliente, sitio o equipo), el formato preferido (PDF o HTML) y si debe salir programado por correo a ciertos destinatarios. Si tienes un ejemplo o un reporte parecido, adjúntalo.

What to include in your request

To speed things up, tell us: what information you want to see (machines, software, patches, alerts…), how to group it (by client, site, or machine), the preferred format (PDF or HTML), and whether it should go out scheduled by email to certain recipients. If you have an example or a similar report, attach it.
